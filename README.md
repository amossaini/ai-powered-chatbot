# AI-Powered Chatbot

An AI-powered customer support chatbot built with Python, Flask, Natural Language Processing (NLP), and SQLite. The application provides contextual responses to user messages and stores conversation history for interaction tracking.

## 🚀 Features

- AI-powered conversational responses
- Context-aware conversations
- Clean and responsive chat interface
- User and bot message bubbles
- Typing/loading indicator while generating responses
- Enter key to send messages
- Shift + Enter for multi-line messages
- Clear Chat functionality
- Conversation timestamps
- SQLite-based interaction logging
- Recent conversation history
- Dedicated History page
- Clear conversation history option
- Input validation and error handling
- Responsive design for desktop and mobile

## 🛠️ Technologies Used

- **Python** – Backend programming
- **Flask** – Web framework and API
- **NLP / Transformers** – Natural language processing and AI responses
- **SQLite** – Conversation and interaction storage
- **HTML5** – Web structure
- **CSS3** – User interface styling
- **JavaScript** – Dynamic chat interaction
- **Jinja2** – Flask template rendering
